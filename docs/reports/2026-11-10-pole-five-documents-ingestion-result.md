## 추출·검토 범위

- PPTX 일반 텍스트뿐 아니라 묶인 도형 안의 텍스트와 표 셀을 슬라이드 순서에 따라 포함했다. 제안요청서의 표 데이터도 검색 근거에 포함한다.
- 절곡설명은 두 슬라이드 모두 이미지여서 기본 텍스트 추출 결과가 비어 있었다. 두 이미지를 직접 읽어 원본 해시에 연결된 검토 전사 텍스트를 작성했다. 저장·재시도·감사 로그는 기존 DocumentService를 사용했고, 승인 전에 슬라이드 위치와 내용을 대조했다.
- 구성도의 4~16번 슬라이드 화면 이미지를 직접 확인하여 화면명·주요 입력·메뉴·기능을 검토 요약으로 보완했다. 요약에는 명시적으로 `화면 이미지 검토 요약`을 표기했다. 실제 업무 데이터의 모든 행·수치나 마스킹된 비밀번호를 전사한 결과가 아니다.
- 이미지 전사는 이번 문서 처리의 일회성 검토 보완이다. 플랫폼에 PPTX 이미지 전체를 자동 광학 문자 인식(OCR)하는 기능을 새로 구현한 것은 아니다.
