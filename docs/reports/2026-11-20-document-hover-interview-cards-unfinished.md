# 문서함 등록 정보와 인터뷰 카드 운영 반영 대기

2026-11-20 작성. 기준 커밋 `f8b76fc7`에서 문서함과 인터뷰 화면을 수정했다.

## 확인 결과

- 공용·개인 문서함의 문서 정보 영역에 마우스를 올리거나 키보드 포커스를 두면 등록 정보를 보여 준다. 실제 컴포넌트를 사용한 브라우저 시험에서 파일명, 크기, 태그, 등록 정보 표시와 긴 설명 스크롤, Escape 닫기를 확인했다.
- 기존 운영 인터뷰 화면의 카드 4개는 데스크톱에서 각각 100px였다. 변경 컴포넌트는 실제 앱 스타일을 적용한 브라우저 시험에서 1524px 화면 47px, 390px 화면 41~47px로 표시됐다. 이관율 막대와 건수 3개가 표시됐다.
- 관련 테스트 11개와 TypeScript 검사가 통과했다. 로컬 앱은 로그인 화면으로 이동해 로그인 이후의 통합 화면은 확인 대기 중이다.
