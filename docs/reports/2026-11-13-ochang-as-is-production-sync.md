## 의심 / 프로브 / 결과 / 재발방지

- 의심: PostgreSQL JSONB 객체 키 순서가 달라 동일한 흐름도를 충돌로 오판할 수 있다.
- 프로브: 첫 로컬 대조에서 동일한 흐름도 23개가 모두 충돌로 검출됐다. 동기화 스크립트의 흐름도 해시 비교 위치를 모두 검색하고 실제 저장 JSON과 입력 JSON을 대조했다.
- 결과: 원인은 객체 키 순서였고, 객체 키만 정렬하되 배열 순서를 유지하는 공통 비교 함수로 수정했다. 같은 로컬 대조가 충돌 0개로 통과했고, 운영 저장 후 모든 흐름도 대조도 통과했다.
- 재발방지: 모든 동기화 해시 비교가 공통 정규화 함수를 사용한다. 실제 입력/저장 대조가 같으면 통과하고, 단계 배열이나 값이 다르면 충돌로 중단한다. 기존 로컬 입력 스크립트의 문자열 필드 비교와 동일 DB 스냅샷 비교에는 이 문제의 동일 조건이 없음을 확인했다.
