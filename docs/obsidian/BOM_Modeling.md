# BOM Modeling

tags: #bom #modeling #warehouse

## BOM

- 베트남 법인 BOM 구조 변화 보고 자료가 공유됐다.
- BOM 운영 방안 협의 자료가 공유됐다.
- PCBA/HNS 유상/무상 자재 구분 자료가 공유됐다.

## 모델링/창고 흐름

- 베트남행성 창고흐름도 자료가 공유됐다.
- MES 모델링 정의서는 `2.2.3.행성사_베트남 법인 MES 구축_MES모델링정의_v1.7`까지 버전 변경됐다.
