# Weekly Report

tags: #weekly-report #wbs-master

## 운영 기준

- 주간보고는 금요일 16시까지 작성한다.
- 특이사항이 없으면 1장만 작성해도 된다.
- 프로젝트 선택은 `행성 MESV2`로 맞춰야 주차가 정상 표시된다.

## 기능 정책

- 사용자별 주간보고 관리가 반영됐다.
- 제출 완료 후 수정 불가, 제출 취소 후 수정 가능.
- 삭제 시 확인 컨펌 창을 띄운다.
- 전주 계획 자동 로딩은 전주 계획을 금주 진행상황으로 이어 쓰기 위한 기능이다.

## 발견된 이슈

- 내가 작성하지 않으면 다른 사람 보고서가 보이지 않는 문제가 있었다.
- 캐시 때문에 다른 사용자의 보고서가 내 화면에 보이거나 수정 가능한 문제가 있었다.
- 제출 완료 버튼 비활성/작동 불가 이슈가 있었다.
