# Open Issues

tags: #open-issues #todo #decision

## ERP/MES

- 스페어파츠의 최종 품목유형 코드 확인.
- 주문/출하 쪽 로케이터 컬럼 추가 여부 및 MES 처리 가능 여부 확인.
- `xwip_mes_status` 연계 시 MES 상태값 정의와 호출 시점 확정.
- 멕시코처럼 ERP 인사정보가 없는 법인의 작업자 정보 수집 방식.

## WBS/주간보고

- WBS 주간 추이표가 필요하면 스냅샷 저장 주기와 데이터 모델 확정.
- WBS 상태/지연/달성률 컬럼의 최종 UI 기준과 엑셀 계산식 기준 동기화.
- 주간보고 자동 로딩, 제출/취소, 사용자별 조회 권한 회귀 테스트.

## 설비/현장

- 설비 인터페이스 대상에서 제외/유지할 설비 목록 최종 확정.
- 마이콤 로트 추적 필수 수집 항목과 설비 인터페이스 방식 확정.
- TESTOP PLC 개조 제외 범위와 소켓 유효성 체크 범위 확정.
- DISPLAY 모델체인지 시퀀스 및 자동 수집 가능 데이터 정의.

## 업무 프로세스

- 기타입출고 항목을 MES UI에서 어떻게 오류 없이 선택하게 할지 정책 결정.
- HNS 외주 입출고 리스트 출력 양식과 ERP/MES 작성 주체 확정.
- IVI SLMS 인터페이스 구성안 상세 설명 및 회의 필요.
