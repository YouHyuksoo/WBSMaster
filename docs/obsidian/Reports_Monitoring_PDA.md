# Reports Monitoring PDA

tags: #report #monitoring #pda

## 리포트

- 리포트 설계문서가 공유됐다.
- 불필요한 리포트 설계서는 `삭제` 폴더로 이동하는 방식이 제안됐다.
- 리포트 설계서 ZIP은 현업 공유용으로, 엑셀에서 설계서 링크가 연결되도록 구성됐다.

## 모니터링/PDA

- 모니터링 설계서가 공유됐다.
- PDA 설계서 및 프로토타입이 공유됐다.
- PDA Android 기본 설정 가이드 문서가 공유됐다.
- HNS 배판공정 실적 처리에 사용하는 Android 태블릿 OS 버전 확인 요청이 있었다.
