# Material Inventory

tags: #inventory #material #erp-interface

## 품목 유형

- `1`: 제품.
- `2`: 반제품.
- `3`: 원자재.
- `4`: 상품.
- 스페어파츠 최종 품목유형 코드는 추가 확인 필요.

## 소모품/스페어파트

- 비용 처리 대상이며 수불을 타지 않는 것으로 공유됐다.
- `CP1`: 사용 후 잔여물이 남지 않는 소모품.
- `CP2`: 사용 후 잔여물이 남는 소모품.

## 기타입출고

- ERP 기타입출고는 입고/출고 구분 없이 모든 항목이 입고와 출고 모두 가능하다.
- `불용 폐기`처럼 출고 성격 항목도 정정 처리를 위해 입고 등록이 가능해야 한다.
- MES UI에서는 사용자 오류를 줄이기 위한 선택 안내가 필요하다.
