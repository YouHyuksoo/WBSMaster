# Project Overview

tags: #mes-v2 #project #vietnam

## 개요

- 대상은 행성사 베트남 법인 [[MES V2]] 구축과 [[ERP_Interface]] 연계다.
- 주요 범위는 [[WBS_Master]], [[Weekly_Report]], [[MES_Views]], [[Equipment_Interface]], [[SLMS_IVI]], [[Shipping_Sales]], [[Material_Inventory]]다.
- 자료와 산출물은 [[Documents_SharePoint]] 기준으로 관리한다.
- 민감정보는 이 지식베이스에 저장하지 않는다.
