# SLMS IVI

tags: #slms #ivi #interface

## 방향

- IVI는 그대로 사용하고 MES V2에 데이터를 최대한 자동화해 수불 데이터를 ERP로 보내야 한다.
- IVI SLMS 데이터를 MES V2를 통해 인터페이스할 예정이다.
- 관련 자료: `행성 베트남 SLMS 운영 구성안(26.05.12)_V0.3.pptx`.
- 해당 PPT는 설명 없이는 이해가 어렵다는 피드백이 있어 회의가 필요하다.

## 참고 자료

- IVI 설비 LOG 수집 데이터.
- 위즈코어 수집 데이터.
- 과거 베트남 수불 데이터 정리 컨셉 자료.
- HMES 자료.
- 멕시코 IVI 소켓/설비 인터페이스 자료.

## SLMS 작업 순서 예

- 작업자ID.
- 현재 자재릴.
- 신규 자재릴.
- 메이커바코드, 없으면 품번 바코드 스캔.
