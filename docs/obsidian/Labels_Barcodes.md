# Labels Barcodes

tags: #label #barcode #quality

## 라벨

- 라벨 포맷 참고자료가 공유됐다.
- Label Spec은 `100 * 50` 규격이 맞는 것으로 공유됐다.
- 실제 부착 테스트로 작업성을 확인해야 한다.

## 바코드/검사

- 업체별 Maker 바코드 포맷 자료가 공유됐다.
- 검사 항목 등록 양식 문서가 공유됐다.
- 수리/폐기 코드 위치와 PCBA 수리/폐기 코드집 최종본 with QR이 공유됐다.
- 베트남 자료에는 코드까지 있었으나 현재 확인 자료에는 항목만 Tree 구조 Level2로 있는 상태가 확인됐다.
