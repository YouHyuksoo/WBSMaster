# Equipment Interface

tags: #equipment-interface #mes-v2 #plc

## 기본 방향

- MES V2 설비 인터페이스 대상 공정/설비 및 업체정보 확인 요청이 있었다.
- 설비 비가동현황 엑셀 관리 템플릿이 공유됐다.
- 기존 DLL 설비 인터페이스 방식을 MES V2에서도 유지해야 하는 이슈가 있다.

## TESTOP

- 검사 전 유효성 체크만 소켓통신으로 적용하는 안이 논의됐다.
- 설비 알람 모니터링을 제외하면 PLC 개조가 불필요할 수 있다.
- 이 경우 비용 절감 가능성이 있다.
